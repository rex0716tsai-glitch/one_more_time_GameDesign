這一次的個人專題採 Game Jam 形式：課程給一個主題，每個人各自從這個主題發展出自己的遊戲。題目分成三層，三層都要滿足。 主題（Theme）：再一次 / One More Time 限制（Constraint）：玩家必須至少重複一次相同的遊戲情境 翻轉（Twist）：第二次不能只是「變強」，而要因為第一次的經驗產生新的玩法 交件要求 一個完整循環要在 5 分鐘內玩得完。「完整循環」是指從開始、經過那一次重複、到看得出結果為止。短沒關係——三分鐘玩完也可以，我們不在意長度下限；上限是為了試玩的人，太長沒有人玩得完。 發布在
