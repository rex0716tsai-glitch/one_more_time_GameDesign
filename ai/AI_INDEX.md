# AI Working Guide

Please read the following documents in order before working on this project:

1. ../README.md
2. 00_AI_Rules.md
3. 01_Understand.md
4. 02_Summarize.md
5. 03_Plan.md
6. 04_Implement.md
7. 05_Review.md

After completing Understand or Summarize, continue automatically to the next stage.

After completing Plan, stop and wait for the user's explicit confirmation before proceeding to Implement. See 03_Plan.md for what counts as confirmation.

At the start of every new task, re-identify which stage applies before proceeding — do not assume a previous task's confirmation carries over.
